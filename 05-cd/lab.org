* Part 1: Build an artifact (20 min)

*A* is the author, *B* the reviewer.

*A*:

#+end_src

Create =build.py=:

#+begin_src python
"""Build the shop's web page into site/index.html."""
import os

from cart import shipping, total

ITEMS = {"Notebook": 4, "Pen": 2, "Backpack": 45}
VERSION = os.environ.get("GITHUB_SHA", "dev")[:7]

def page(items, version):
    prices = list(items.values())
    rows = "".join(f"<li>{name}: {price}</li>" for name, price in items.items())
    return f"""<!doctype html>
<html>
<head><meta charset="utf-8"><title>Shop</title></head>
<body>
<h1>Shop</h1>
<ul>{rows}</ul>
<p>Total, taxes included: {total(prices)}</p>
<p>Shipping: {shipping(prices)}</p>
<p><small>Version {version}</small></p>
</body>
</html>
"""

if __name__ == "__main__":
    os.makedirs("site", exist_ok=True)
    with open("site/index.html", "w") as f:
        f.write(page(ITEMS, VERSION))
    print("Built site/index.html, version", VERSION)
#+end_src

and =test_build.py=:

from build import page

    assert "Version abc1234" in html
#+end_src

* Part 2: Deploy after every merge (25 min)

*B* is the author, *A* the reviewer.

*B*:

#+begin_src bash
git switch -c cd/pages
#+end_src

At the end of =.github/workflows/ci.yml=, under =jobs:=, add two jobs (same indentation as =test:=):

#+begin_src yaml
  build:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: python build.py
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site

  deploy:
    needs: build
    if: github.event_name == 'push'
    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
#+end_src

#+begin_src bash
git commit -am "Deploy the web page to GitHub Pages"
git push -u origin cd/pages
#+end_src

* Cheat sheet

#+ATTR_LATEX: :booktabs t :align ll
| *Item*                                   | *Meaning*                                          |
|------------------------------------------+----------------------------------------------------|
| =needs: test=                            | Start this job only when =test= is green           |
| =if: github.event_name == 'push'=        | Run only on a push (a merge into =main=)           |
| =actions/upload-pages-artifact=          | Store the built site as the run's artifact         |
| =actions/deploy-pages=                   | Publish that artifact on GitHub Pages              |
| =environment: github-pages=              | The target; its protection rules apply             |
| Settings > Environments > Required reviewers | Turn deployment into delivery: a person approves |
| Revert button on a merged PR             | A new PR that undoes it                            |
| =vMAJOR.MINOR.PATCH=                     | Breaking change . new feature . bug fix            |
