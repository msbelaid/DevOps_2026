* Part 3: Issue, pull request, review (25 min)

*B* is the client and the reviewer, *A* is the author.

*B*, on GitHub: Issues > New issue.
- Title: =Add shipping cost=
- Description: =Shipping costs 5. It is free from 50 (before taxes).=

*A*:

#+begin_src bash

#+end_src

Add at the end of =cart.py=:

#+begin_src python
FREE_SHIPPING_FROM = 50

def shipping(prices):
    """Shipping cost: free from 50, before taxes."""
    if sum(prices) > FREE_SHIPPING_FROM:
        return 0
    return 5
#+end_src

In =test_cart.py=, also import =shipping= in the first line, and add at the end:

#+begin_src python
def test_shipping_small_cart():
    assert shipping([20]) == 5

    assert shipping([100]) == 0
#+end_src

#+begin_src bash

git commit -am "Add shipping cost"
git push -u origin feature/shipping
#+end_src

* Part 4: A bug, test first (20 min)

Roles swap: *A* is the client and the reviewer, *B* is the author.

*A*, open an issue:
- Title: =Discount over 100% gives negative prices=
- Description: =apply_discount([100], 150) returns [-50.0]. A discount must be between 0 and 100.=

*B*:

#+begin_src bash
git switch main && git pull
git switch -c fix/discount-limit
#+end_src

First reproduce the bug with a test. At the top of =test_cart.py=, add =import pytest=, and at the end:

#+begin_src python
def test_discount_over_100_is_refused():
    with pytest.raises(ValueError):
        apply_discount([100], 150)
#+end_src

#+begin_src bash
pytest                           # 1 failed: the bug is reproduced
#+end_src

Then fix =apply_discount= in =cart.py=:

#+begin_src python
def apply_discount(prices, percent):
    if not 0 <= percent <= 100:
        raise ValueError("percent must be between 0 and 100")
    return [p * (1 - percent / 100) for p in prices]
#+end_src

#+begin_src bash
pytest                           # all passed
git commit -am "Refuse discounts outside 0-100%"
git push -u origin fix/discount-limit
#+end_src

Open the pull request: =Closes #<issue number>=, reviewer *A*.

*A*: review it as in Part 3 (read, run =pytest= on the branch). Is a negative discount refused too? Approve or request changes.

*B*: Squash and merge, Delete branch. Both: =git switch main && git pull=.

* Cheat sheet

#+ATTR_LATEX: :booktabs t :align ll
| *Command / action*                       | *Purpose*                                   |
|------------------------------------------+---------------------------------------------|
| =pytest=                                 | Run all =test_*= functions of =test_*.py=   |
| =pytest -v= / =pytest -k discount=       | Verbose / only tests matching a name        |
| =with pytest.raises(ValueError):=        | Check that an error is raised               |
| =git push -u origin <branch>=            | Publish a new branch                        |
| =git fetch= then =git switch <branch>=   | Get a colleague's branch to review it       |
| =Closes #N= in a PR description          | Close issue N when the PR is merged         |
| Review changes > Approve / Request changes | Give your review decision                |
