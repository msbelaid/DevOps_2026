* Part 2: A feature, and an urgent bug (20 min)

Start a feature on its own branch:

#+begin_src bash
git switch -c feature/discount
#+end_src

Append to =cart.py=:

#+begin_src python
def apply_discount(prices, percent):
    return [p * (1 - percent / 100) for p in prices]
#+end_src

#+begin_src bash
git diff                         # review before committing
git commit -am "Add percentage discount"
#+end_src

A user reports a crash: an empty cart breaks the app.

#+begin_src bash
git switch main                  # your feature is safe on its branch
python3 -c "from cart import average; average([])"    # ZeroDivisionError
git switch -c fix/empty-cart
#+end_src

Fix =average= in =cart.py=:

#+begin_src python
def average(prices):
    if not prices:
        return 0
    return sum(prices) / len(prices)
#+end_src

#+begin_src bash
git commit -am "Fix crash on empty cart"
git switch main
git merge fix/empty-cart         # 1st merge
git merge feature/discount       # 2nd merge (accept the default message)
git lg
python3 main.py
#+end_src

** 5.1 Both on main: feel the problem

Both students change the first line of =README.md= differently, commit, then push. *A* pushes first.

* Cheat sheet

#+ATTR_LATEX: :booktabs t :align ll
| *Command*                              | *Purpose*                              |
|----------------------------------------+----------------------------------------|
| =git status= / =git diff [--staged]=   | What changed / what is staged          |
| =git add <file>= / =git commit -m=     | Stage / record a change                |
| =git switch [-c] <branch>=             | Change (create) branch                 |
| =git merge <branch>=                   | Merge a branch into the current one    |
| =git rebase <branch>=                  | Replay my commits on top of a branch   |
| =git restore [--staged] <file>=        | Discard a change / unstage             |
| =git commit --amend=                   | Fix the last commit (not pushed!)      |
| =git revert <id>=                      | Undo a pushed commit                   |
| =git pull= / =git push=                | Get / send commits                     |
| =git lg=                               | History as a graph                     |
